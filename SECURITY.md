# Security Policy

## 🛡️ Supported Versions

We actively provide security patches and updates for the following versions:

| Version | Supported          |
| :------ | :----------------- |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## 🚨 Reporting a Vulnerability

The SmartHire security team takes security vulnerabilities seriously. If you discover a vulnerability, please follow responsible disclosure guidelines:

1. **Do NOT** open a public issue on GitHub.
2. Email your report directly to **aminurhstu23@gmail.com**.
3. Include the following details in your report:
   - Type of issue (e.g., SQL injection, IDOR, privilege escalation, token leak)
   - Step-by-step reproduction instructions
   - Proof of Concept (PoC) code or requests
   - Potential impact of the vulnerability

### ⏱️ Response Timeline
- **Initial Acknowledgement:** Within 24 hours
- **Assessment & Triage:** Within 72 hours
- **Fix & Disclosure:** As soon as reasonably practicable

Thank you for helping keep SmartHire and our users safe!
